# Contributing Guide

> **Language:** English | [中文](./CONTRIBUTING.md)

This repository is a bot project that automates the repository creation workflow.

## Modifying Bot Logic

1. Fork this repository
2. Modify `scripts/repo_creator.py`
3. Submit a PR describing your changes
4. Wait for review and merge

## Modifying Issue Templates

Issue templates are located in the `.github/ISSUE_TEMPLATE/` directory.
