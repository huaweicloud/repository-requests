# Security Policy

> **Language:** English | [中文](./SECURITY.md)

## Reporting Security Vulnerabilities

**Do NOT report security vulnerabilities publicly via GitHub Issues.**

Please report security vulnerabilities by email to huaweiclouddev@huawei.com.

We commit to:
- Confirming receipt within 48 hours
- Providing an initial assessment within 7 days
- Notifying reporters promptly after a fix is released
